# 闪寻 FlashFind 0.2.1（预览版）

0.2.1 是修复版，修复了点击列头不排序的问题。

## 修复

- **点击列头排序**：在 0.2.0 中，点击“名称 / 路径 / 大小 / 修改时间”列头不会重新排序。原因是主窗口收不到列表控件的列点击通知（LVN_COLUMNCLICK）。现在由列表自己处理列头点击：
  - 再次点击同一列，在升序和降序之间切换。
  - 点击新的列时，名称和路径默认升序，大小和修改时间默认降序。
  - 列头箭头同步更新；排序设置会保存。
- **快速连点切换**：快速连点同一列头时，第二下会被识别为双击。现在它也算一次点击，正常切换升序/降序，并且不会重复计数。
- **名称排序更稳健**：不再假设搜索结果已按名称排列（原来只做反转）。
  - 结果较少时，直接按名称比较排序。
  - 结果较多时，按全局名称顺序并行排序。

## 性能（约 232 万对象）

| 排序 | 耗时 |
|---|---|
| 全部对象按名称（升 / 降） | 26 / 46 ms |
| 18,196 个结果按名称 | 2.4 ms |
| 100,400 个结果按名称 | 7.0 ms |
| 全部对象按路径 / 大小 / 时间 | 56–64 ms |

## 测试

- 新增 `-sortclicktest`：用真实鼠标输入点击列头，逐列校验升序、降序和箭头。
