# 闪寻 FlashFind 0.3.1（预览版）

0.3.1 是修复与小功能版，在 0.3.0 之上改进结果列表选中显示，并加入按住空格预览。

## 修复

- **切换选中项高亮残留**：结果列表为自绘。原先选中/焦点变化时，ListView 只按内部行矩形做局部失效，与自绘行高、顶行错位时，旧高亮会留在屏幕上。现在在选中/焦点变化、鼠标点选以及键盘导航后整块客户区重绘。

## 新增

- **按住空格预览**（列表有焦点时）：
  - **按下空格**显示浮层，**松开空格**关闭；Esc 或窗口失活也会关闭。
  - **图片**：经系统 WIC 解码（jpg/png/gif/bmp/tiff/ico，以及系统已安装编解码器时的 webp/heic 等），等比缩放居中。
  - **文本**：常见源码/文档扩展名；按 UTF-16 BOM、UTF-8（含 BOM）、否则系统 ANSI 解码；大文件只读前缀（约 512 KiB）并提示截断。
  - **多选**：优先预览焦点行（若在选中集合中），否则选中的第一项。
  - 无法识别为图片或文本时，空格无操作。属性仍用 **Alt+Enter**。

## 说明

- PDF、Office、音视频等不在空格预览范围内。
- `.svg` 按文本预览源码；`.rtf` 按纯文本（可见控制字）。
