# 闪寻 FlashFind 0.3.2（预览版）

0.3.2 修复按住空格预览「按下无效果」的问题。

## 修复

- **按住空格预览立即消失**：预览浮层原先以 ShowWindow(SW_SHOW) 显示并会抢占激活。主窗口随即收到 WA_INACTIVE，在同一按键流程里立刻关掉预览；随后主窗重新激活时又把焦点拉回搜索框，表现为按下空格完全没反应。
  - 预览改为 WS_EX_NOACTIVATE，并以 SWP_NOACTIVATE | SWP_SHOWWINDOW 显示，不抢激活。
  - 主窗失活时若即将激活的是预览窗则不关闭；按住空格期间不把焦点抢回搜索框。
  - 预览加载失败时不再置「按住」标志，避免吞键后无反馈。

## 使用说明

- 空格预览仅在**结果列表有焦点**时生效（搜索框内空格仍为输入空格）。先点选或 ↓ 进入列表，再按住空格。
- 图片（WIC）与常见文本；松开关闭。属性仍用 Alt+Enter。
