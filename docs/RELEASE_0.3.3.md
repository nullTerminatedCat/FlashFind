# 闪寻 FlashFind 0.3.3（预览版）

0.3.3 汇总自 0.3.2 以来的预览体验、粘贴修复与性能小优化。

## 修复

- **搜索框 Ctrl+V**：原先全局拦截为空文件粘贴（CF_HDROP），文本剪贴板也会报「粘贴失败」。现与剪切/复制一致，仅结果列表焦点时文件粘贴；搜索框恢复系统文本粘贴。
- **按住空格预览激活**：浮层不抢激活，避免主窗 WA_INACTIVE 立刻关掉预览。

## 预览体验

- 小窗贴在**文件名列右侧**（不再铺满主窗 / 不再用整行右下）。
- **固定尺寸**约 320×240（DPI 缩放），图片等比居中显示。
- **外框透明**（色键），去掉大块黑底；文本预览保留小面板以保证可读。

## 性能 / 打磨

- 输入搜索 **50ms 防抖**（标题栏即时更新；开关/筛选/排序仍立即搜索）。
- 键盘导航与滚动去掉同步 UpdateWindow，减轻连按时全表重绘卡顿。
- 已选超过 2000 项时状态栏不再逐条累加体积。
- 选项页快捷键说明同步上述行为。

## 使用提示

- 空格预览需**结果列表有焦点**（先点行或 ↓）。
- 搜索框 Ctrl+V = 文字；列表 Ctrl+V = 粘贴文件到选中文件夹。
