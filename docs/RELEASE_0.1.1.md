# 闪寻 FlashFind 0.1.1（预览版）

## 新功能：通配符搜索

与 Everything 相同的通配符：

- `*` 匹配任意多个字符（包括零个），`?` 匹配恰好一个字符。
- 含通配符的词匹配**整个文件名**：`1*.exe` 匹配 `123.exe`，不匹配 `a1.exe` 或 `1.exe.bak`；`*.exe` 只匹配以 `.exe` 结尾的名称。
- 词中含 `\` 时匹配**完整路径**（从盘符开始），例如 `*\windows\*.dll`。
- 不含通配符的词仍按子串匹配；可与空格分隔的多个词（AND）及 `"..."` 短语组合，例如 `report *.docx`。
- 不区分大小写（与其他搜索相同的折叠规则）；结果高亮按通配符拆分出的字面片段。

### 性能

每次搜索只编译一次模式；`前缀*`、`*后缀`、`前缀*后缀`、`*x*` 走无回溯快速路径，其他模式用迭代算法（无递归，不会因 `*a*a*a*b` 之类的模式卡住）。

在约 232 万对象的真实索引上（16 线程，7 次取最好）：

| 搜索词 | 耗时 |
|---|---|
| `exe`（子串） | 30.9 ms |
| `1*.exe` | 16.4 ms |
| `*.exe` | 15.4 ms |
| `a?c` | 15.4 ms |
| `*a*e*.?x?` | 34.2 ms |
| `**` | 0.3 ms |

## CI 与测试

- 修复 0.1.0 首次发布时 CI 失败：`-incrtest` 在没有数据库的构建机上使用合成索引时找不到测试目标；合成索引加入大目录并提高采样密度。
- 自检输出同时写到 stdout，CI 日志可直接看到失败项。
- ctest 新增 `wildtest`（通配符单元用例 + 大索引耗时）与 `incrtest_synthetic`。
- 安装脚本改为带 BOM 的 UTF-8，确保安装界面中文正常显示。

## 已知限制

与 0.1.0 相同：FlashFind 服务的真实安装/运行、LocalSystem 读取 MFT、经服务读取 USN 等需要管理员的路径尚未在真实环境中充分验证；`?` 按 UTF-16 单元计数（emoji 等代理对需要 `??`）。
