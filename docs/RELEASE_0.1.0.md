# 闪寻 FlashFind 0.1.0（预览版）

Windows 上的极速文件名搜索工具，参考 voidtools Everything 1.4。原生 Win32 + C++20，静态 CRT 单 exe，无第三方依赖。

> ⚠️ 这是第一个预览版本，部分需要管理员权限的功能尚未在真实环境中充分验证，见下方“已知限制”。

## 主要功能

- 输入即搜：后台多线程搜索，空格分隔多词（AND）、`"..."` 短语、含 `\` 时匹配完整路径；约 226 万对象搜索约 20 ms。
- NTFS 主文件表（MFT）直接建库 + USN 日志实时增量更新（新建/删除/改名/修改），无需启动时重新扫描。
- 数据库持久化（v4 格式）：226 万对象加载约 0.2 秒。
- 文件夹删除通过父→子反向索引移除整棵子树；移入的文件夹立即扫描并加入索引；已删除条目定期压缩。
- 每卷设置：包含/排除目录、仅包含列表、监视开关、USN 开关（ini 兼容 Everything 的数组写法）。
- 全局热键 Ctrl+Alt+Space、双击 Ctrl、托盘、浅色/深色主题、Win11 Mica、PerMonitorV2 DPI。

## FlashFind 索引服务（推荐）

读取 MFT 和带文件名的 USN 记录需要管理员权限。闪寻提供一个 LocalSystem 服务，只负责特权读取；界面以普通权限运行，通过命名管道（仅本机交互用户可访问，并校验服务进程）与服务通信。

安装方式（任选其一）：

1. 程序内：**工具 → 安装 FlashFind 服务…**（或状态栏的盾牌按钮 / 托盘通知），确认 UAC 后安装，无需重启程序即继续索引。
2. 安装包：选择“为所有用户安装”，并勾选“安装 FlashFind 索引服务”。
3. 命令行（管理员）：`FlashFind.exe -install-service`；卸载：`FlashFind.exe -uninstall-service`。

服务日志：`%ProgramData%\FlashFind\FlashFind-service.log`。卸载程序会自动停止并删除服务（需以管理员模式安装）。

不安装服务也不以管理员运行时，已有数据库仍可搜索，但 NTFS 卷无法建库或实时更新，状态栏会提示安装服务。

## 已知限制

- 以下功能仅在非管理员环境下做了协议层测试，真实服务环境尚未充分验证：服务安装/启动、LocalSystem 读取 MFT、经服务读取 USN、属性列表（$ATTRIBUTE_LIST）大小查询、断线重连、移入文件夹的服务端扫描。
- 便携版若安装了服务，服务路径指向该 exe；移动或删除 exe 前请先卸载服务。
- 任何本机交互用户都可通过服务列出所有卷的文件名（与 Everything 服务类似）。
- 仅支持 NTFS 本地固定磁盘的 MFT/USN；其他卷使用目录遍历。
- 暂无文件内容搜索、正则、书签、网络（ETP/HTTP）等功能。
