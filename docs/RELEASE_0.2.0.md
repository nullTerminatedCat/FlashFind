# 闪寻 FlashFind 0.2.0（预览版）

0.2.0 完成 M2 的主要功能：完整搜索语法、PCRE2 正则、列排序、过滤器、系统右键菜单、文件操作和若干界面修复。

## 搜索

- **搜索语法**：空格 = 与，`|` = 或，`!` = 非，`< >` 分组，`"..."` 短语；函数 `ext:`、`size:`、`dm:`、`path:`、`file:`、`folder:`；通配符 `*` `?`。
- **正则表达式**（PCRE2 10.44，UTF-16，JIT）：`regex:` 前缀，或 搜索 > 启用正则表达式（Ctrl+R，默认关闭，`match_regex`）。不区分大小写；正则中含 `\\` 时匹配完整路径；编译错误显示在状态栏。
- **过滤器下拉框**：全部 / 音频 / 压缩文件 / 文档 / 可执行文件 / 文件夹 / 图片 / 视频。
- **列头排序**：名称 / 路径 / 大小 / 修改时间，再点一次切换升降序；只改排序时不重新搜索。

约 232 万对象的真实索引上的耗时：

| 查询 | 耗时 |
|---|---|
| `ext:exe` | 15.6 ms |
| `*.exe` | 19.2 ms |
| `regex:\.exe$` | 28.9 ms |
| `regex:^report` | 27.0 ms |
| `regex:^[a-z]+\d{3,}\.(jpg\|png)$` | 29.0 ms |
| `regex:windows\\system32\\.*\.dll$`（完整路径） | 60.5 ms |
| 全部对象按路径/大小/时间排序 | 55–62 ms |

正则只编译一次（< 0.1 ms）。

## 文件操作

- **重命名**（F2，`allow_rename=1`）：单项就地编辑（文件只选中主名）；多项打开对话框，每行一个新名称，支持查找/替换，可跨文件夹。使用 IFileOperation，可撤销。
- **删除**：Del 进回收站；Shift+Del 确认后永久删除。
- **拖出**：把结果拖到资源管理器或其他程序（复制 / 移动 / 快捷方式），可跨文件夹。
- **右键菜单**：所选项都在同一文件夹时合并系统右键菜单（`single_parent_context_menu=1`）；否则使用闪寻自己的菜单。

索引通过 USN 日志自动反映这些变化。

## 界面

- **选项对话框**（工具 > 选项，Ctrl+P）：常规、键盘（全局热键录入与冲突检测）、NTFS 卷、排除。
- **列显示/隐藏**：列头右键，或 视图 > 列。
- **真实图标**：exe / lnk / ico / url 等在后台线程加载，只加载可见行。
- **深色菜单栏**：深色主题下菜单栏与弹出菜单也是深色。这一功能依赖 Windows 未公开的接口。
- **修复滚动重影**：滚动和键盘导航后整块重画（约 1.8 ms）。自检程序把屏幕像素与强制重画的结果逐点比较，9 种滚动方式均无差异。

## 稳定性

- 数据库读写加锁：写入方只在“写临时文件 + 重命名”期间持排他锁，读取方只在一次完整读取期间持共享锁；测试读取已安装实例的数据库时先复制一份。

## 第三方

- 静态链接 PCRE2（BSD 许可），见 `THIRD_PARTY_NOTICES.md`。

## 已知限制

- 文件夹大小按 0 排序；路径排序按文件夹树的先序，与字符串顺序个别情况下不同。
- 重命名、删除、拖出、右键菜单和深色菜单栏还没有经过完整的人工界面测试。
